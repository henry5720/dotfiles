# Triage labels

engineering skills 用的 canonical triage role 和對應的 GitHub label：

| Canonical role | GitHub label | 用途 |
|---|---|---|
| `needs-triage` | `needs-triage` | 維護者尚未評估 |
| `needs-info` | `needs-info` | 等待提問者補資料 |
| `ready-for-agent` | `ready-for-agent` | 規格完整，可交給 agent |
| `ready-for-human` | `ready-for-human` | 需要人工實作 |
| `wontfix` | `wontfix` | 不處理 |

另有 `agent-runner`：交給 runner 在人不在時做。`/to-tickets` 拆完、要 AFK 做的 sub-issue，除了 `ready-for-agent` 再一張一張貼 `agent-runner`。
